# ESCAPE.HTML

> You opened a website. Something else opened you.

一个运行在浏览器中的互动电影与数字艺术原型。完整体验包含极简入口、行为校准、界面反抗、二维页面破裂、WebGL 数字建筑、行为生成生命体，以及最终的逃离与数字身份凝结。

## 运行

环境要求：Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run start
```

完整检查：

```bash
npm test
npm run lint
```

## 核心体验

- 六段连续章节状态与可访问的跳过动态选项
- 集中的 Interaction Engine，统一记录指针、速度、加速度、点击、滚轮、输入、长按、停留与窗口焦点
- 仅保存在浏览器本地的行为痕迹
- 指针速度驱动的文字散射、按钮躲避、重排输入、掉落词语与逐级异常
- 可拖拽的页面裂缝，以及纯 HTML 面板向 WebGL 场景同步展开的连续转场
- React Three Fiber 程序化走廊、UI 碎片、空间粒子与行为生成数字生命体
- 完整逃离序列、稳定的数字身份分类与 2400 × 1350 PNG 身份卡导出
- 可恢复同一身份卡的分享链接、系统原生分享与剪贴板回退
- 刷新或意外离开后的本地章节检查点恢复，且可随时清除后重新开始
- 站点专属 Open Graph / X 分享预览图与动态来源地址
- 触摸屏布局、键盘操作、清晰焦点、`prefers-reduced-motion` 与运行时错误恢复

## 第三阶段：沉浸层

- 数字生命体使用实时顶点位移和边缘发光 Shader，根据移动速度与异常值持续变形
- 中、高画质启用单通道屏幕空间折射、色散、扫描线与暗角合成，高画质额外启用受控柔光
- 渲染器在三秒预热后按四秒窗口采样帧率；高画质低于 44 FPS 自动降为中画质，中画质低于 31 FPS 自动降为低画质
- 低画质绕过全部后处理、减少粒子和细分；减少动态效果模式同样使用直接渲染路径
- Web Audio 使用 HRTF Panner、程序化卷积混响和动态压限，环境声源在三维空间内缓慢运行
- 指针位置控制监听者位置，点击脉冲从实际点击坐标发声，章节切换会改变空间展开程度、滤波与混响

## 第四阶段：连续性与恢复

- 体验开始后每秒保存一次版本化章节检查点，并在页面转入后台或关闭时补写最终状态
- 检查点仅在当前设备保留七天；恢复前会校验章节、数值范围、文本长度与轨迹数组上限，损坏或过期记录会被自动丢弃
- 再次打开页面时提供“继续检查点”与“清除并重新开始”两个明确选择，不会在未确认时自动跳转
- 访问他人分享的身份链接会直接进入分享结果，不读取或覆盖当前设备上的个人检查点
- 恢复时同步异常程度、裂缝进度、声音偏好、停留时间和行为指标；旧版本地记录会静默迁移
- 恢复对话框具有初始焦点、键盘焦点约束、触摸屏布局和语义化说明，系统控制操作不会污染行为分类

## 数据与素材

项目不要求登录，不采集真实身份信息，不向服务器上传行为数据。行为痕迹仅写入当前浏览器的 `localStorage`。

视觉与声音均使用 CSS、Three.js 几何体、程序化 Shader、粒子和 Web Audio API 生成，不含外部图片、模型、音乐或音效。
